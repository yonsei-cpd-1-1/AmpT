# vision

OPC 점·규격 인식 (Python + OpenCV). 사진은 Pi 카메라로 찍고, 판별은 노트북에서 돌린다.

| 파일 | 내용 |
|---|---|
| `size.py` | 빈 칸 사진과 비교 (`bg`) → 윤곽 → 높이 · 몸통 폭. `bg`가 없으면 어두운 곳을 찾는다 (가짜 앰플용) |
| `dot.py` | 머리 쪽 색 점 (빨강 · 노랑 · 파랑) → 규격 + 각도 θ = asin(dx / r) |
| `detect.py` | 사진 폴더 → 결과 표 + 정답 대조 (`--bg` 빈 칸 사진, `--debug` 그린 사진 저장) |
| `live.py` | 노트북 카메라 미리보기, b/f 키로 사진 저장. 화면의 판별은 빈 칸 비교를 안 써서 실물에는 참고만 |
| `calib.py` | 체커보드(9 × 6)로 렌즈 왜곡 보정값 |
| `specs.py` | 앰플 치수 표. 10/31 카메라 측정과 달라 자로 다시 잰 뒤 고친다 |
| `config.py` | 임계값 전부 — 실물 사진 보고 여기서 조정 |
| `tests/` | 코드로 그린 가짜 앰플로 파이프라인 확인 (실물 성능과 무관) |

- 실물: 갈색 앰플은 역광에서 빛나고 투명 앰플은 배경과 밝기가 같아 **빈 칸 사진과 비교**해 윤곽을 찾는다. 규격은 **점 색**으로 정한다 (손에 있는 1 · 2 mL은 모양이 거의 같다).
- `.venv/bin/python vision/detect.py vision/samples/ --bg vision/samples/bg_back_000_01.jpg --debug vision/samples/debug`
- 유리가 비쳐 180° 점이 0° 점처럼 보인다 → 사진 한 장으로는 앞뒤를 못 가른다. 코드에는 아직 없다.
- `config.DIFF_ROI`는 집 세팅의 종이 안쪽이다. 기계에서는 다시 잡는다. 바닥 그림자를 자르며 전체 높이가 조금 짧게 나오므로 치수 측정에는 쓰지 않는다.
- 사진 이름: `{규격}_{back|front}_{점방향}_{번호}.jpg` — 같은 자리에서 조명만 바꿔 back · front 한 쌍 (10/31 사진은 조명을 안 바꿔 두 장이 같다). `vision/samples/`의 사진 20장은 저장소에 들어 있다.
