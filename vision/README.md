# vision

OPC 점·규격 인식 (Python + OpenCV). 노트북(아이폰 연속성 카메라)으로 먼저 개발하고 Pi로 옮긴다.

| 파일 | 내용 |
|---|---|
| `size.py` | 역광 사진 → 실루엣 → 높이 · 몸통 폭 → 1 / 2 / 5 mL |
| `dot.py` | 정면광 사진 → 머리 쪽 빨간 점 → 각도 θ = asin(dx / r) |
| `detect.py` | 사진 폴더 → 결과 표 + 정답 대조 (`--debug`로 그린 사진 저장) |
| `live.py` | 카메라 미리보기 + 판별 결과, b/f 키로 사진 저장 |
| `calib.py` | 체커보드(9 × 6)로 렌즈 왜곡 보정값 |
| `specs.py` | 앰플 실측 치수 (설계/04 §3-1) |
| `config.py` | 임계값 전부 — 실물 사진 보고 여기서 조정 |
| `tests/` | 코드로 그린 가짜 앰플로 파이프라인 확인 (실물 성능과 무관) |

- 카메라는 앰플 축 둘레로 비스듬히(29°) 보지만, 원통 실루엣은 어느 방향에서 봐도 같다 → 규격은 **높이 ÷ 폭 비율**만으로 가른다 (1 mL 5.0 · 2 mL 6.0 · 5 mL 4.5). 배율을 알면 `--mm-per-px`로 mm 판별.
- 사진 이름: `{규격}_{back|front}_{점방향}_{번호}.jpg` — 같은 자리에서 조명만 바꿔 back · front 한 쌍.
